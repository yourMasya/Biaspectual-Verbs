# Biaspectual-Verbs
 My coursework made on the third year of studying at HSE "Fundamental and Applied Linguistics". The code consists of several blocks:
 * **Wiki-dictionary web-parser**, collecting bi-aspectual verb list and morphonological mark-up
 * **Russian National Corpus** web-parser for bi-aspectual verb context and mark-up (including morphological, syntactic and semantic properties) collection 
 * `rubert-tiny2` model for aspect disambiguation
